# Changelog

## 0.1.0 — initial preview

- Independent hover visibility for Blizzard Action Bars 1–8, Pet Bar, and Stance / Form Bar.
- Optional linked reveal, configurable combat visibility, and fixed smooth fade timings.
- Native settings panel with global defaults and retained independent character profiles.
- Visibility support for editing, keybinding, cursor dragging, and spell flyouts.
- Pause control when known action-bar replacements are loaded.
- Lua 5.1 behavior/integration tests and installable ZIP packaging.

Live-client verification is pending; see the in-game checklist before treating this preview as verified for gameplay.
